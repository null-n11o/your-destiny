# your-destiny 設計

作成日: 2026-10-16。対象は友人向け天中殺試作。この文書は実装計画の前の設計である。製品コードは、この文書と実装計画の確認後に書く。

## 目的

友人が自分のスマホで生年月日を入れ、天中殺の種類と短い文をその場で読む。結果は声に出して約60秒で読み終える長さにする。同じ暦日は、ページを開き直しても同じ種類と同じ本文になる。

成功の確認は、公開の日柱例と判定が一致することである。支払い、登録、公開からの訪問は成功に含めない。

## 範囲

入力は西暦の年、月、日である。時刻と呼び名は置かない。判定はページを開いたあとのブラウザ内で終え、生年月日をサーバー、外部AI、URL、保存領域へ出さない。

画面に出すのは、種類の一文、人との距離、今夜の場面、隣への問い、同じ天中殺の芸能人である。注記、相性、時期の天中殺、年柱、月柱、星の一覧、課金、アカウント、専門家表示は出さない。

配信先は Cloudflare Pages の Free とする。URL は `*.pages.dev` を使う。独自ドメインは買わない。Pages Functions と Workers は置かない。アクセス解析は置かない。

## 構成

Vite が TypeScript を静的ファイルへまとめる。UI に React は使わない。入力と結果は、同じページの DOM を書き換える。テストは Vitest で、純関数を Node 上で確認する。Node.js 22 以上を使う。

ファイルの役割は次のとおりである。

| 場所 | 役割 |
|---|---|
| `src/domain/date.ts` | 年月日が実在する暦日かの判定 |
| `src/domain/pillar.ts` | 日柱の番号、干支、6種類への対応 |
| `src/content/copies.ts` | 6種類の本文と芸能人名 |
| `src/ui/app.ts` | 入力と結果の切り替え |
| `public/_headers` | 検索エンジンへ載せない指定 |
| `src/domain/pillar.test.ts` | 公開例と60通りの確認 |

## 画面とデータの流れ

ページは1枚である。入力と結果を切り替え、両方を同時には出さない。

入力は年、月、日の3欄だけを置く。いずれも西暦の数値である。操作は「見てみる」だけである。受け付ける暦日は1900年1月1日から2099年12月31日までとする。2月29日はグレゴリオ暦のうるう年だけ通す。

「見てみる」は通信しない。ページ遷移も起こさない。三つの数は画面の中から純関数へ渡す。端末のタイムゾーンで日付をずらさない。

純関数が6種類のうち一つを返したときだけ、結果を次の順で出す。

1. 種類の名前と一文
2. 人との距離。薄い縁を2行、大切にする縁を2行
3. 今夜の場面を一つ
4. 隣への問いを一つ。隣の人に、一つの出来事を尋ねる
5. 同じ天中殺の芸能人。名前を3人、説明は書かない

横スクロールはさせない。1列にする。ブロックをこの5つより増やさない。

結果の下に「入れ直す」を置く。押すと結果を消し、空の入力へ戻す。保存はしない。生年月日はURL、localStorage、sessionStorage、cookie、外部送信へ出さない。ページを閉じると残らない。

欄の値は整数として読む。空白だけの欄は未入力とする。未入力、範囲の外、存在しない日では結果を出さない。未入力のときは「年、月、日を入れてください。」と出す。それ以外で計算できないときは「その日は存在しません。入れ直してください。」と出す。

## 本文

6種類の一文は、比べる対象を両側で同じ種類の語にする。問いの「それ」「その件」「今の話」は、隣の人との直前の会話を指す。画面は会話の中身を保存しない。

### 子丑天中殺

目上との縁よりも、目下との縁を大切にする。

父や上司の用事は後回しになりやすい。先輩に相談されても深入りしない。後輩が困っていると自分から動く。年下の話は最後まで聞く。

上司の話は聞き流す。後輩が失敗した話だと自分から理由を聞く。

最近、年下に頼まれて引き受けたことは何だ？

綾瀬はるか、明石家さんま、タモリ。

### 寅卯天中殺

友人や兄弟との縁よりも、家庭との縁を大切にする。

友人の誘いは後回しにする。兄弟の近況は聞き流す。配偶者の話は最後まで聞く。家の予定は自分から入れる。

友人の近況は流す。家の話になると具体的になる。

今日の話を家に帰って誰にする？

木村拓哉、宇多田ヒカル、福山雅治。

### 辰巳天中殺

気持ちを話すことよりも、実行することを大切にする。

気持ちの吐露は短く終える。なぜそう感じるかは後回しにする。次に何をするかは自分から決める。作業の話になると自分から口を出す。

気持ちの話が続くと席を外したくなる。次に何をするかの話になると前に出る。

今の話を次にやるのはいつだ？

新垣結衣、石原さとみ、浜崎あゆみ。

### 午未天中殺

目下との縁よりも、目上との縁を大切にする。

後輩の相談は短く終える。年下の失敗には深入りしない。上司の評価は覚えている。父や先輩の話は最後まで聞く。

後輩の相談は短く切る。上司の話になると内容を覚えている。

上司か先輩にその件を伝えるとき、最初の一言は何だ？

大谷翔平、橋本環奈、松本潤。

### 申酉天中殺

家庭との縁よりも、友人や兄弟との縁を大切にする。

配偶者の話は短く終える。家の予定は後回しにする。友人の誘いは自分から受ける。兄弟の近況は最後まで聞く。

家の話は一文で終える。友人の話題だと自分から広げる。

その話を最初に伝える友達は誰だ？

米津玄師、安室奈美恵、二宮和也。

### 戌亥天中殺

実行することよりも、気持ちを話すことを大切にする。

次に何をするかの段取りは後回しにする。作業の話は短く終える。なぜそう感じるかは自分から聞く。気持ちの話だと最後までいる。

段取りの話は後回しにする。気持ちの話だと長くいる。

その件のどこに納得していない？

菅田将暉、有村架純、平野紫耀。

## 日柱の計算

日柱は西暦の年月日だけから決める。時刻は使わない。日付の境は午前0時であり、23時では変えない。

2000年1月1日を戊午とする。甲子を0と数えると、戊午の番号は54である。対象の日付との差を日数で取り、54に加えて60で割った余りが、その日の番号になる。差が負のときは60を足してから余りを取る。差はグレゴリオ暦の日付差であり、`Date.UTC` による日付の引き算で求める。スマホのローカルタイムゾーンは使わない。存在しない日は、この計算の前に拒否する。

十干は番号を10で割った余り、十二支は12で割った余りである。この対応は60日で一巡する。番号の範囲で種類を一つに決める。

|---|---|---|
| 0〜9 | 甲子旬 | 戌亥天中殺 |
| 10〜19 | 甲戌旬 | 申酉天中殺 |
| 20〜29 | 甲申旬 | 午未天中殺 |

| 40〜49 | 甲辰旬 | 寅卯天中殺 |
| 50〜59 | 甲寅旬 | 子丑天中殺 |

## 確認

Vitest で次を固定する。

- 2000年1月1日は戊午、番号54、子丑天中殺である
- 1985年3月12日は庚戌、番号46、寅卯天中殺である
- 2011年9月26日は甲申、番号20、午未天中殺である
- 番号0から59のすべてで、その日の支は天中殺の2支に入らない
- 上表の18人は、それぞれの番号と種類になる
- 空欄、1900年より前、2099年より後、2月31日、平年の2月29日では結果を返さない
- 同じ暦日を二度計算すると、同じ種類と同じ本文になる

2000年1月1日と1985年3月12日の干支は、KnowYourBaZi の日柱の説明（2026-10-16閲覧）に合わせる。2011年9月26日の干支は、shihei.com の計算記事（2026-10-16閲覧）に合わせる。

## 配信

ビルド成果物は `dist` である。`public/_headers` で全パスに `X-Robots-Tag: noindex` を付ける。HTML にも `noindex` を書く。

Cloudflare への配置と、友人への URL 共有は、その操作の明示承認があるまで行わない。配置するときは静的ファイルだけを置く。

## 要件定義v1からの変更

2026-10-16の確認で、要件定義v1から次を変えた。

- 注記の3点は画面に出さない
- 呼び名は初回の対象外にする
- 同じ天中殺の芸能人を、名前3人だけ足す
- 結果の下に「入れ直す」を置く
- 配信先を Cloudflare Pages の Free に固定する

有料商品、相性、時期の天中殺は、この設計に入れない。
